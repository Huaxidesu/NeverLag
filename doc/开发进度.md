## 2026-11-12：1.5.4

| 模块 | 内容 |
|---|---|
| 精英词表 | `tools/gen_autonames.py` 从汉化包 InfernalMobs 语言文件提取 69 个前缀 + 73 个后缀，生成 `autoname_zh_cn.txt` 打进 jar |
| 判定 | `AutoNames.matches()` 做包含匹配，命中即认为不是玩家起名；**只对敌对生物生效**，避免误删叫「凤凰」的宠物 |
| 加载 | `onEnable` 里紧接 `MobNames.load()` 之后 `AutoNames.load()`，日志打印词条数 |

### 实测（server2：1.5.4，端口 25599）

| 场景 | 结果 |
|---|---|
| 苦力怕「剧毒的旺财」（前缀） | 清掉 |
| 苦力怕「不死者」（后缀） | 清掉 |
| 苦力怕「旺财」 | 保留 |
| 狼「凤凰」（友好生物） | 保留，词表不对友好生效 |

### 已知限制

- 词表来自 InfernalMobs，别的模组自造的随机名（Sli、Bartleby）仍识别不了。

## 2026-11-12：1.5.3

| 模块 | 内容 |
|---|---|
| 自动命名 | 新增 `ClearAutoNamed`（默认 true）：名字里带本体基础种类词的（无敌的僵尸 / 剧毒骷髅）视为模组生成，照常清理 |
| 判定依据 | `MobCleaner.isAutoNamed()` 三条：与英文名相同、与本类型中文名相同或包含、类继承链命中 `BASE_WORDS` 且名字带种类词 |

### 实测（server2：1.5.3，端口 25599）

| 场景 | 结果 |
|---|---|
| `无敌的苦力怕`（前缀 + 基础种类词） | `clear now` 后消失 |
| `旺财`（玩家起名） | 仍在，`named` 里标 `[普通]` |
| `小白`（命名的羊） | 仍在 |
| 反例：只比类型名 | 「无敌的僵尸」的实体是 `SpecialMobs.FishingZombie`，类型名「钓鱼僵尸」不含，故必须走继承链判定 |

### 已知限制

- 随机名（Sli、Bartleby 这种，不带种类词）无法识别，只能靠 `ClearNamedHostile: true`。

## 2026-11-11：1.5.1

| 模块 | 内容 |
|---|---|
| 精英怪 | 新增 `ClearInfernal`（默认 true）：读实体持久 NBT 的 `InfernalMobsMod` 判定精英怪，命中后无视自定义名照常清理 |
| 诊断 | 新增 `/neverlag named`：按名字聚合列出被「命名保留」挡下的生物，并标出是否带精英怪标记 |

### 实测（server2：1.5.1，端口 25599）

| 场景 | 结果 |
|---|---|
| 带 `ForgeData.InfernalMobsMod` + 名字的僵尸 | `/neverlag named` 标为 `[精英]` |
| 只带名字的僵尸 | 标为 `[普通]`，`clear now` 后仍存活 |
| `clear now` | 清理完成 3 只，精英怪被清，玩家命名的僵尸保留 |

### 已知限制

- NBT 读不到时（其它服务端实现）一律按「不是精英怪」处理，此时只能靠 `ClearNamedHostile` 或名单。
